# Apex OS v1

Apex OS coordinates research, sales, content, delivery, and quality review around one shared knowledge layer.

## Operating pattern

Research → Plan → Create → Review → Approve → Publish

## Non-negotiable rules

1. Automate consistency, not decisions.
2. A human approves client-facing claims, proposals, pricing changes, and final publishing.
3. Every factual claim must have a source or be marked unverified.
4. Draft and final production are separate steps.
5. Failed work is routed to review rather than silently published.

## Folder map

- `knowledge/` — shared company, audience, offer, proof, and writing rules
- `agents/` — role instructions and required outputs
- `workflows/` — handoffs, approval points, and system maps
- `templates/` — repeatable briefs, scorecards, and outputs

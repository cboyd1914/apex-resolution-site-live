# Apex QA Rubric

Score each category from 0–5. A client-facing asset must score at least 4 in every category. Any hard failure sends it to human review.

## Categories

1. **Audience fit** — speaks to a home-service owner and a real operating problem.
2. **Clarity** — plain words, short sentences, clear next step.
3. **Claim support** — each factual claim has a source or is marked unverified.
4. **Offer fit** — recommendation matches confirmed needs.
5. **Proof use** — proof points are accurate, contextual, and anonymized.
6. **Action** — one specific CTA.
7. **Brand match** — follows BRAND.md.
8. **Risk** — no invented facts, hidden assumptions, or unsupported financial promises.

## Hard failures

- Invented company facts
- Unverified statistics presented as fact
- Client name exposed in a case example
- Automatic publishing without approval
- Automatic pricing, contract, or scope decision
- Missing source for a claim

## Review loop

1. Identify the failed rule.
2. Rewrite only the affected section.
3. Re-score.
4. Stop after three attempts.
5. Route unresolved work to human review with the failure reason.
